# Foodie Recipe App — User Stories

1. **Account registration:** As a new user, I want to create an account using my username, email address, and password so that I can access my personal Foodie experience.
2. **Account login:** As a returning user, I want to sign in with my email and password so that I can continue using the app and see my saved data.
3. **Discover recipes:** As a food lover, I want to browse recipe cards and categories on the home screen so that I can find ideas for meals that match my interests.
4. **View recipe details:** As a cook, I want to open a recipe and view its image, ingredients, instructions, preparation time, servings, calories, and difficulty so that I can decide how to prepare it.
5. **Save favorites:** As a user, I want to favorite and unfavorite recipes and revisit them in a Favorites section so that I can quickly find recipes I like.
6. **Manage personal recipes:** As a user, I want to add, edit, and delete my own recipes, including an image, ingredients, and instructions, so that I can maintain my personal collection.
7. **Keep data between sessions:** As a user, I want my account session, favorites, personal recipes, and preferences to be saved locally so that my information is still available after I close and reopen the app.
8. **Discover external recipes:** As a user, I want the app to fetch recipe information from an external recipe API so that I can explore more dishes beyond the sample recipes.
9. **Manage settings and notifications:** As a user, I want to open a settings menu, manage notification preferences, and send a test notification so that I can control how the app communicates with me.
